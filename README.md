# sait_postyplenia

Личный трекер поступления в магистратуру 2026.

Публичная версия сайта:

https://laplaceram.github.io/sait_postyplenia/

Сайт показывает конкурсные группы РЭУ по УКП `2420603`.

Основные данные обновляются в браузере каждые 10 минут из публичного API РЭУ. Запрос использует только header `apikey`, без `Authorization`, чтобы не ломать CORS preflight на GitHub Pages.

Также в репозитории есть запасной файл `docs/data/rea-2420603.json`. Если live API временно недоступен, сайт может показать последние сохранённые данные.

Для ручного обновления данных:

```bash
npm run data:update
```
