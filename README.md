# sait_postyplenia

Личный трекер поступления в магистратуру 2026.

Публичная версия сайта:

https://laplaceram.github.io/sait_postyplenia/

Сайт показывает конкурсные группы РЭУ по УКП `2420603`.

Данные обновляются через GitHub Actions каждые 10 минут: workflow запрашивает API РЭУ с серверной стороны, сохраняет результат в `docs/data/rea-2420603.json`, а браузер читает этот локальный JSON. Так сайт не упирается в CORS-ограничения API РЭУ.

Для ручного обновления данных:

```bash
npm run data:update
```
